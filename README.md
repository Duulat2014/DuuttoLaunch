# DuuttoLauncher Emerald Edition 💎

Кастомный лаунчер для Minecraft на базе **ZalithLauncher** с полностью переработанным интерфейсом в уникальной изумрудной стилистике.

## 🌟 Особенности проекта

* **Изумрудный дизайн (Emerald Theme):** Глубокая темная тема (`#0b1210`) в сочетании с технологичным изумрудным акцентом (`#10b981`) и карточным фоном (`#14221b`).
* **Карточный дашборд:** Удобный главный экран с быстрыми переходами к управлению версиями, скинами, настройкам и загрузкам.
* **Нижняя панель навигации (Bottom Navigation):** Эргономичное управление основными разделами приложения.
* **Современная архитектура:** Переход ключевых компонентов интерфейса на **Kotlin**, использование **Jetpack Navigation** и **ViewBinding**.

## 🛠 Технологический стек

* **Базовый проект:** ZalithLauncher (`com.movtery.zalithlauncher`)
* **Языки программирования:** Kotlin, Java
* **Интерфейс:** Material Components, Custom CardViews, BottomNavigationView, EventBus
* **Система сборки:** Gradle / GitHub Actions
